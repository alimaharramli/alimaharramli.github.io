To create a new blog post:

1. Copy this file and rename it (e.g. `my-first-post.md`)
2. Update the frontmatter fields above
3. Write your content in Markdown below the `---`
4. Push to `main` — GitHub Actions builds and deploys automatically

### Supported Markdown

Regular paragraphs, **bold**, *italic*, `inline code`, and [links](https://example.com).

```bash
# code blocks with syntax highlighting
echo "hello world"
```

> Blockquotes work too.
